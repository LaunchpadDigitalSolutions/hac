First aid essentials

CPR ▼
  1. Check for danger, then check for response
  2. Call 999 immediately
  3. 30 chest compressions — hard and fast, 5–6cm deep
  4. 2 rescue breaths (if trained)
  5. Continue 30:2 until ambulance arrives
Choking ▼
  1. Encourage them to cough
  2. 5 firm back blows between shoulder blades
  3. 5 abdominal thrusts (Heimlich manoeuvre)
  4. Alternate back blows and thrusts
  5. Call 999 if not resolved
Severe bleeding ▼
  1. Apply firm direct pressure to the wound
  2. Keep pressing — do not remove dressing
  3. Raise the injured area above the heart if possible
  4. Call 999
Unresponsive person ▼
  1. Check for danger
  2. Shout for help, call 999
  3. Open airway — tilt head, lift chin
  4. Check for normal breathing (10 seconds)
  5. If not breathing — start CPR
  6. If breathing — recovery position
Emergency? Call
999
